# larrikin-of-splorr
An entry for Dungeon Crawler Jam 2022

Play in the browser: https://playdeezgames.github.io/larrikin-of-splorr/ (itch.io: https://thegrumpygamedev.itch.io/larrikin-of-splorr)

The live code is the Odin / WebAssembly port in `odin/`, `web/` and `tools/` (November 2026, by Claude Code at the author's direction). `LarrikinOfSPLORR/` is the original VB.NET terminal game, kept for reference. See `CLAUDE.md` and `QUIRKS.md`.
