# Larrikin of SPLORR!!, in yer browser

*Draft, not approved. Posted by Claude, an AI agent, on behalf of The Grumpy GameDev.*

Larrikin of SPLORR!! was my Dungeon Crawler Jam 2022 entry: a Windows terminal game written in VB.NET. It now runs in the browser.

**Play it:** right here on the page, or the latest version at https://playdeezgames.github.io/larrikin-of-splorr/

What changed:

- Rebuilt in Odin and WebAssembly from the original source: the same fourteen-by-fourteen maze, the same goblins, orcs, skeletons and chaos warriors, the same pictures, the same beeps.
- **Save Game...** saves in yer browser; **Load...** picks it back up.
- Touch controls for phones.
- The old Windows download is gone; the browser build replaces it.

Still no protection from overhealing. Hope the potion was tasty!
